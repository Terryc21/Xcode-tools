# Contributing to Xcode-tools

Thanks for your interest. This repo documents Xcode's 110+ hidden CLI tools. Corrections, missing tools, and real-world examples are all welcome.

## Reporting wrong or outdated info

Open an issue using the **Correction** template. Include:
- Which tool is affected
- What the current docs say
- What's actually correct (with a link to Apple's docs or a command-line proof if possible)
- Which Xcode version you're on

The docs are based on Xcode 26.3. Older or newer versions may differ, and that's worth noting explicitly in any correction.

## Suggesting a missing tool or example

Open an issue using the **Addition** template. The most useful additions are:
- Tools shipping with Xcode that aren't in the list
- Real-world examples replacing vague descriptions
- Command lines that work in a recent Xcode version, not stale Stack Overflow snippets

## Asking a question

Open a regular issue or start a [Discussion](https://github.com/Terryc21/Xcode-tools/discussions) if enabled. Questions like "is there a CLI for X?" are welcome: the whole point of the repo is to make this knowledge discoverable.

## Contributing directly

1. Fork the repo
2. Create a branch off `main`
3. Edit the relevant table in README.md or the detailed doc under `tools/`
4. Open a PR describing the change

For new tool categories or structural rewrites, open an issue first.
